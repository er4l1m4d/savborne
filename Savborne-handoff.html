Savborne build handoff

Savings RPG that runs inside Nimiq Pay. Everything you need to build the mini app: tokens, brand assets, components with React + TypeScript + plain CSS variables, all 30 screens as live recreations with notes, animations and platform rules.

StackReact + TypeScript, plain CSS variables, no UI library.
Design size390 × 844 portrait. Fluid 360–430. Desktop: centered 430px column.
FontsPlus Jakarta Sans (UI) + Silkscreen (numbers, labels, chips, rewards).
Style ruleHard pixel edges. No blur, no soft shadows, no gradients. Radius comes from stepped clip-path corners.

Components

Every component is built from three CSS ideas: the pixel panel (outline + hard shadow via stacked drop-shadow, corners via clip-path), flat 2px borders, and Silkscreen for numbers. States: default, pressed (sink 4px into the shadow), disabled (off colors, not-allowed), focus (mint 2px outline, 2px offset, never removed).

Pixel panel + button (React + TS)

// PixelPanel.tsx — outline + hard shadow come from drop-shadow, corners from clip-path
import type { ReactNode, CSSProperties } from 'react';
type Tone = 'default' | 'mint' | 'coral' | 'cream' | 'off';
const TONES: Record<Tone, { o: string; s: string; bg: string }> = {
  default: { o: 'var(--sv-line)',  s: 'var(--sv-edge)',  bg: 'var(--sv-surface)' },
  mint:    { o: 'var(--sv-mint)',  s: 'var(--sv-edge)',  bg: 'var(--sv-surface)' },
  coral:   { o: 'var(--sv-coral)', s: 'var(--sv-edge)',  bg: 'var(--sv-warn-fill)' },
  cream:   { o: 'var(--sv-text)',  s: '#8E866E',         bg: 'var(--sv-text)' },
  off:     { o: 'var(--sv-off)',   s: '#1B2624',         bg: 'var(--sv-inset)' },
};
export function PixelPanel({ tone = 'default', children, className = '', style }:
  { tone?: Tone; children: ReactNode; className?: string; style?: CSSProperties }) {
  const t = TONES[tone];
  return (
    <div className="pxw" style={{ '--o': t.o, '--s': t.s } as CSSProperties}>
      <div className={`px ${className}`} style={{ background: t.bg, ...style }}>{children}</div>
    </div>
  );
}

// Button.tsx — primary (coral), secondary (surface), disabled (off)
type BtnProps = React.ButtonHTMLAttributes<HTMLButtonElement> & { variant?: 'primary' | 'secondary' };
export function Button({ variant = 'primary', disabled, children, ...rest }: BtnProps) {
  const tone: Tone = disabled ? 'off' : variant === 'primary' ? 'cream' : 'default';
  const t = TONES[tone];
  const primary = variant === 'primary' && !disabled;
  return (
    <div className="pxw sv-btn" style={{ '--o': primary ? 'var(--sv-text)' : t.o, '--s': primary ? 'var(--sv-coral-edge)' : t.s } as CSSProperties}>
      <button {...rest} disabled={disabled} className={`px sv-btn__face sv-btn--${disabled ? 'off' : variant}`}>{children}</button>
    </div>
  );
}

Check-in sequence (implementation order)

  1. Button → loading (sv-dots), call getBalance.
  2. On success: balance-read count-up (600ms).
  3. +10 XP: xp-pop and xp-fill together (700ms).
  4. If streak changes: streak-tick. If XP crossed a level: level-up after xp-fill ends.
  5. If bracket changed: navigate to Bracket Climb after level-up is dismissed.
  6. Button settles to "Checked in today" (disabled).

Queue every celebratory animation through one FIFO so they never overlap. Skip the queue entirely when reduced motion is on, but still show Level-up and Bracket Climb screens (they carry information).
