# Home UI redesign - implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Rebuild Home around the handoff, add the checked-in state and delta, and add `/first-checkin`.

**Architecture:** Home keeps `usePlayerSession` and the check-in POST. The header becomes the product wordmark with bracket/level chips; the display name moves to a character card. The savings card owns the check-in action. `checkInDestination` gains a first-check-in result, and a transient handoff carries the first-check-in summary to a new pushed route.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind plus `.sv-*`/`.pxw`/`.px`, node:test, the existing CDP render harness.

**Spec:** `docs/superpowers/specs/2026-11-09-home-ui-design.md`.

## Global Constraints

- Branch `home-ui-redesign` from `main`; no stacking.
- Use Foundation 2 primitives only. No new `vpx` panels or ad-hoc buttons.
- 12px type floor; 44px targets; 360px no truncation.
- Coral for the advancing CTA; mint for success/progress/you.
- No API/schema changes. The check-in response already carries `awarded`, `previousBalanceLuna`, `bracket`, `unlockedItems`.
- `players.xp` is cumulative; use `xpProgress(level, xp)`.
- One commit per task; full suite green before each commit.
- Never stage ignored environment files.

```ts
export function checkedInToday(lastCheckInAt: string | null, now = new Date()): boolean {
  if (!lastCheckInAt) return false
  const last = new Date(lastCheckInAt)
  if (Number.isNaN(last.getTime())) return false
  return (
    last.getUTCFullYear() === now.getUTCFullYear() &&
    last.getUTCMonth() === now.getUTCMonth() &&
    last.getUTCDate() === now.getUTCDate()
  )
}
```
