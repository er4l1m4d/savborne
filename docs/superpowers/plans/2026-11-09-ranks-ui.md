# Ranks UI redesign - implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development or superpowers:executing-plans.
> Steps use checkbox (`- [ ]`) syntax.

**Goal:** Port `/leaderboard` ("Ranks") to the handoff: Ranked/Unranked tabs,
Everyone/Friends 44px filter chips, one grouped panel of 56px rows, a
mint-bordered 60px You row, a pinned your-rank row when outside the top 50, and
the board-specific footer.

**Architecture:** The page keeps its single `GET /api/leaderboards` fetch and
adds the Missions 401 redirect. A pure `src/lib/ranks-ui.ts` owns the rank tone,
footer copy, friends-empty test and pin decision. Two additive Foundation 2
primitives (`FilterChip`, `Row variant="you"`) plus one art component
(`RankCrown`) carry the handoff anatomy. The API gains one additive `you` field;
`rows`, `total`, the sorts and the friends filter do not change.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind plus
`.sv-*` / `.pxw` / `.px`, node:test, the existing CDP render harness.

**Spec:** `docs/superpowers/specs/2026-11-09-ranks-ui-design.md`.

## Global Constraints

- Branch `ranks-ui-redesign` from `main` at `646e85f`; no stacking.
- Foundation 2 primitives only. No `vpx`, no ad-hoc panels/buttons/filter chips.
- 12px type floor; 44px targets; 360px no truncation.
- Selected filter chip is cream fill with ground text; mint is reserved for the
  tabs, progress/success and the You row.
- The friends definition (human battles), the ranking logic and the unranked
  score mapping do not change. The only API addition is `you`.
- One commit per task; `npm test`, `npx tsc --noEmit`, `npm run lint` and
  `npm run build` green before each commit.
- Never stage `.env.local`, `AGENTS.md` or InstaBox tooling.
- The capture harness lives in `/data/tmp/opencode/` and is not committed.

```ts
/**
 * Savborne - Ranks display helpers
 *
 * Pure copies and decisions for the Ranks screen. The ranking rules stay in
 * /api/leaderboards; nothing here reorders or rescores a board.
 */

export type Board = 'ranked' | 'unranked'

/** Ranks 1-3 read as strong text, 4+ as muted, as the handoff draws them. */
export function rankTone(rank: number): 'strong' | 'muted' {
  return rank <= 3 ? 'strong' : 'muted'
}

export function boardFooter(board: Board): string {
  const line =
    board === 'ranked'
      ? 'Ranked points from human ranked battles.'
      : 'Savings score from check-in growth and consistency.'
  return `${line} Only display names are shown, never addresses or balances.`
}

/**
 * The API always includes the caller, so a Friends board with no other player
 * is a list of one. Treat it as empty rather than as a one-row list.
 */
export function isFriendsEmpty(rows: { isMe: boolean }[]): boolean {
  return rows.every((row) => row.isMe)
}

export function shouldPinYou(
  rows: { isMe: boolean }[],
  you: { rank: number } | null,
): boolean {
  return you !== null && !rows.some((row) => row.isMe)
}

export function footerLegend(total: number, anyVerified: boolean): string {
  const players = `${total} player${total === 1 ? '' : 's'}`
  return anyVerified ? `${players} · ⟡ verified saver` : players
}
```
